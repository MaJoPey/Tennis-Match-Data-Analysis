# 🎾 Tennis Data Analysis

A Python-based exploratory data analysis project investigating professional tennis statistics, player characteristics, match outcomes, serving performance, and tournament trends.

## 📌 Project Overview

This project uses Python and statistical analysis to explore tennis data through **17 main research questions and 8 additional questions**. Using Pandas, NumPy, Matplotlib, Seaborn, and SciPy, the notebook examines player performance, match statistics, court surfaces, and relationships between key variables.

## 🔍 Key Research Questions

- Which player has the highest number of wins?
- Is there a correlation between player height and ranking?
- How do serving statistics differ by gender?
- Are higher ace counts associated with winning matches?
- Are more double faults associated with losing matches?
- Which court surfaces and tournament categories are most common?
- Which players perform best against top-10 opponents?

## 📊 Selected Findings

- **Aces and winning:** Players with more aces won 64.88% of 8,084 matches in which the sides had different ace counts.
- **Double faults and losing:** Players with more double faults lost 62.51% of 8,735 matches in which the sides had different double-fault counts.

These findings indicate associations rather than causation.
